====================================================================
           PANDUAN MENJALANKAN SISTEM SKRIPSI (UNTUK WILLIAM)
====================================================================

Halo William! Ikuti 3 langkah mudah ini untuk menjalankan aplikasi:

--------------------------------------------------------------------
LANGKAH 1: INSTALL 2 SOFTWARE WAJIB (Hanya 1x Saja)
--------------------------------------------------------------------
Jika laptop Windows kamu belum ada Python dan Node.js, install dulu:

1. PYTHON:
   Download: https://www.python.org/downloads/
   [PENTING] Saat buka installer, WAJIB CENTANG kotak paling bawah:
   "[x] Add python.exe to PATH"
   Lalu klik "Install Now".

2. NODE.JS:
   Download: https://nodejs.org/ (Pilih versi LTS)
   Buka file installer, klik Next -> Next -> Install sampai selesai.

3. TESSERACT OCR (Khusus fitur baca tulisan plat di kertas):
   Download: https://github.com/UB-Mannheim/tesseract/wiki
   Download file: tesseract-ocr-w64-setup-5.x.x.exe, install sampai selesai.

--------------------------------------------------------------------
LANGKAH 2: JALANKAN APLIKASI (CUKUP DOBEL KLIK!)
--------------------------------------------------------------------
1. Di dalam folder ini, cari file bernama:
   start.bat

2. KLIK DUA KALI (Double-Click) file "start.bat" tersebut!

3. Sistem akan otomatis menyiapkan semua dependensi AI dan web,
   lalu otomatis membuka browser ke:
   http://localhost:3000

(Catatan: Khusus saat pertama kali dijalankan, proses download library
butuh waktu 1-3 menit tergantung internet. Untuk kali berikutnya,
langsung nyala dalam 3 detik!).

--------------------------------------------------------------------
LANGKAH 3: MATIKAN APLIKASI
--------------------------------------------------------------------
Untuk mematikan aplikasi, cukup tutup 2 jendela hitam (CMD)
yang tadi terbuka di taskbar kamu.

--------------------------------------------------------------------
BERKAS SKRIPSI LENGKAP SIAP PAKAI:
--------------------------------------------------------------------
Buka folder "docs" di dalam folder ini:
- docs\BAB_3_METODOLOGI_PENELITIAN.md (Diagram & Rumus Bab 3)
- docs\BAB_4_HASIL_DAN_PEMBAHASAN.md   (Tabel Uji & Metrik Bab 4)
- docs\PANDUAN_SIDANG_DAN_DEMO.md     (Kunci Jawaban Sidang Penguji)

Untuk panduan lebih lengkap dengan gambar, buka file:
HOW_TO_RUN.md
